A customizable header or footer notification bar with per-page visibility and display control.

== Description ==
Add a lightweight and customizable header or footer notification bar with per-page visibility, custom messages, and display behavior control.

== Features ==
* Header or footer position
* Custom colors
* Close button option
* Show once or always
* Disable per post/page
* Custom message per post/page

== Screenshots ==
1. Plugin settings page.
2. Header bar displayed on the frontend.
3. Per-page visibility settings in post editor.

== Installation ==
1. Upload plugin folder to /wp-content/plugins/
2. Activate plugin
3. Configure under Settings
